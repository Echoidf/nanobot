# 设计方向确认

## 已选方向

方向 A：输入框任务抽屉。

## 第二轮调整

- 不把 ReAct 与任务拆解表达成非此即彼的模式。
- LLM 根据任务复杂度自然创建和结束结构化任务列表。
- 抽屉是只读状态展示，不是项目管理控制台。
- 不展示关闭模式、取消计划、暂停计划或步骤菜单按钮。
- 用户可以随时发送消息打断下一任务调度。
- LLM 根据用户消息调用结构化任务工具更新 completed、cancelled 等状态。
- 用户手动完成任务时，状态证据明确标记为用户提供。
- 含义不明确或匹配多个任务时，通过对话澄清。

## 原型

评审原型：`direction-a-composer-drawer.html`。

方向 B、C 不进入实施，仅保留为历史评审稿。
